GameZone è una web app sviluppata in React che permette agli utenti di esplorare videogiochi, cercarli e salvare i propri preferiti all’interno di un profilo personale.

L’app include un sistema di autenticazione e gestione utenti realizzato con Supabase, con funzionalità come login, registrazione, upload dell’avatar e salvataggio dei giochi preferiti nel database.

Dal punto di vista tecnico ho utilizzato React con React Router per la navigazione, Tailwind CSS e DaisyUI per l’interfaccia, e React Hook Form per la gestione dei form.

Il progetto è completamente responsive, con un approccio mobile-first.

La UI è stata sviluppata con ricerca dei colori,disposizione degli elementi e font a gusto personale, il logo, la favicon e l'immagine Header di Homepage sono generate con AI ma inventate da me su come volevo che fossero (esempio: la "M" di game a forma di controller).

L’obiettivo è stato quello di simulare una vera applicazione full-stack moderna, lavorando sia sulla parte frontend che sull’integrazione con un backend reale.
